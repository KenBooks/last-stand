# Portrait artwork tool

The root and tools AGENTS.md apply. `portraits.mjs` uses the lab’s existing low-priority headless browser to export square PNG originals or square crops of supplied sheets to 192px WebP, quality 0.82, at most 20000 bytes each. A manifest supplies classId, two-digit id, source path and prompt, optionally a shared original filename and crop `{x, y, size}`. It requires the same positive number of unique pictures per supplied class. Existing exports are preserved unless `--replace` explicitly archives and replaces them. Originals, previous exports, prompts and a contact sheet are preserved in `.tmp/portrait-art/`; tracked provenance merges only supplied IDs. Its browser/temp files stay in `tools/portraits/out/`. Use built-in Codex image generation for new paintings; this tool only crops/normalizes dimensions/encoding.
