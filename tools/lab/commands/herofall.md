# `lab herofall`

`npm run lab -- herofall --class mage` gives the hero a lethal hit in a solo run and follows his model through the
knee buckle, backward landing, rebound and settled pose. It checks the lowest drawn solid vertex of the settled body
and gear against the floor. Run as `mage`, `ranger` or `warrior` and use the usual fixture options to change gear.
`--canary` lowers the settled pose by 30 cm and requires the floor check to detect it.
